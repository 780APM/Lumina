# Lumina v0.1.0 — Your music. Offline.

The first packaged release of Lumina: a portable Windows music player for the
audio files on your computer, with album artwork and reactive visualizers.

## Download and run

1. Download **Lumina.exe** from the assets below.
2. Open the EXE — no separate Python installation is required.
3. Choose **Add Files**, select your local audio, and press **Play**.

This build is for 64-bit Windows. It was built and tested locally on Windows 11.
The executable is unsigned, so Windows may display a publisher/reputation warning.

## Included in this release

- MP3, FLAC, WAV, and OGG playback streamed from disk.
- Titles, artists, albums, embedded artwork, sidecar covers, and generated fallback art.
- Persistent native Tk Canvas visualizers in 2D and circular modes; optional Matplotlib 3D mode.
- Playback timeline, seek previews, shuffle, playlist looping, and keyboard shortcuts.
- Volume adjustment by dragging or scrolling, plus mute.
- Stable timeline layout while long song titles scroll.
- Custom accent colors and the Lumen application icon.

## Verification

All **22 regression tests passed** locally. Real audio-device checks covered
streaming playback, volume changes, pause, seek, resume, and both native canvas
visualizer modes. The EXE includes the required miniaudio/CFFI extensions and
runtime icon assets.

Local frame measurements improved from approximately 9 ms to 2.5 ms for 2D,
and 31 ms to 5 ms for circular visualization. These are local measurements,
not guarantees across hardware. Optional 3D retains its existing renderer.

## Release assets

| File | Contents |
| --- | --- |
| `Lumina.exe` | Standalone Windows player |
| `Lumina-Lumen-brand-kit.zip` | Logo, Windows ICO, launch banner, social poster, brand guide, and copy |
| `SHA256SUMS.txt` | SHA-256 checksums for the downloadable files |

To check a downloaded file in PowerShell:

```powershell
Get-FileHash .\Lumina.exe -Algorithm SHA256
```

Compare the result with the matching entry in `SHA256SUMS.txt`.

## Current scope

- Supported audio extensions are MP3, FLAC, WAV, and OGG. AAC/M4A, WMA, and other
  formats are not included in this version.
- The playlist is session-based; a saved music-library manager and metadata
  editor are not implemented yet.
- Music playback is offline. There are no streaming accounts or online music
  lookups.

Source and artwork are included in the repository under its MIT license.
